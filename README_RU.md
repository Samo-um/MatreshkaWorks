# MATRESHKARP_WORKS — стартовый проект

В проекте есть:
- регистрация и вход по email/паролю;
- прайс-лист;
- создание заказов и просмотр своих заказов;
- личные обращения в чатах;
- роли `director`, `admin`, `player`;
- серверная проверка прав для назначения/снятия администраторов;
- Android-проект WebView-оболочки для будущего APK.

## Важно
Это исходный проект, а не готовый подписанный APK. Для настоящего приложения нужно:
1. Установить Node.js 20+ и SQLite.
2. Задать `JWT_SECRET` и `DIRECTOR_EMAIL` в переменных окружения.
3. Запустить backend и проверить его.
4. Разместить веб-интерфейс и API на HTTPS-хостинге.
5. В `android/app/src/main/java/com/matreshkarp/works/MainActivity.java` заменить `https://YOUR-HTTPS-DOMAIN.example` на адрес размещённого приложения.
6. Собрать APK в Android Studio (Build > Build APK(s)).

Первый зарегистрированный пользователь с email, совпадающим с `DIRECTOR_EMAIL`, получает роль владельца. Не оставляйте секреты в коде. Для production рекомендуется Firebase/Supabase или полноценная проверка email, rate limiting, резервные копии, HTTPS и аудит действий.

## Запуск backend
```bash
cd backend
npm install
JWT_SECRET="replace-with-a-long-random-secret" DIRECTOR_EMAIL="you@example.com" npm start
```
API по умолчанию слушает `http://localhost:3000`. Веб-интерфейс можно открыть через локальный статический сервер из папки `web`, но API URL в `web/app.js` нужно установить в `http://localhost:3000`.

## Возможности / ограничения стартовой версии
- Заказы и чаты сохраняются в SQLite на сервере.
- Администраторы не могут назначать/снимать администраторов или менять владельца.
- Владелец не может быть снят через обычный endpoint.
- Прайс-лист в этой версии демонстрационный и редактируется в `web/app.js`.
- Для production стоит добавить подтверждение email, сброс пароля, защиту от перебора паролей, политику приватности и правила обработки персональных данных.

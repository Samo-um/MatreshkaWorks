# Как запустить MATRESHKARP_WORKS онлайн

## Что потребуется
- Компьютер или облачный сервер с Docker и Docker Compose.
- HTTPS-домен/адрес для публичного приложения.
- Свой email, который станет владельцем (`DIRECTOR_EMAIL`).

## 1. Запустить API на сервере
В корневой папке проекта создайте `.env`:
```env
JWT_SECRET=ВСТАВЬТЕ_ДЛИННЫЙ_СЛУЧАЙНЫЙ_СЕКРЕТ_МИНИМУМ_32_СИМВОЛА
DIRECTOR_EMAIL=ваш_email@example.com
```
Не публикуйте `.env` и никому не отправляйте секрет.

Затем выполните:
```bash
docker compose up -d --build
```
Проверка:
```bash
curl http://localhost:3000/api/health
```
Ожидается JSON с `ok: true`.

## 2. Разместить веб-интерфейс
Разместите содержимое папки `web` на HTTPS статическом хостинге (например, Cloudflare Pages, Netlify или другом). Перед публикацией в `web/app.js` измените:
```js
const API_BASE = "http://localhost:3000/api";
```
на публичный HTTPS URL API, например:
```js
const API_BASE = "https://api.ВАШ-ДОМЕН/api";
```
Замените только на ваш настоящий адрес. Настройте CORS в `backend/server.js` под домен интерфейса вместо открытого `cors()` перед production.

## 3. Владелец
Сначала задайте `DIRECTOR_EMAIL` в `.env`. Затем зарегистрируйте именно этот email в приложении — этот аккаунт получит роль Director. Если этот email уже зарегистрирован с другой ролью, не меняйте роль вручную без резервной копии и проверки базы.

## 4. Android APK
В `android/app/src/main/java/com/matreshkarp/works/MainActivity.java` замените:
```java
private static final String APP_URL = "https://YOUR-HTTPS-DOMAIN.example";
```
на настоящий HTTPS адрес веб-интерфейса. Откройте папку `android` в Android Studio, дождитесь синхронизации Gradle и выберите **Build > Build APK(s)**.

## Безопасность перед реальным использованием
Этот архив — стартовый прототип, а не готовая production-система. Перед использованием с реальными игроками:
- настройте HTTPS, ограниченный CORS, резервные копии и мониторинг;
- добавьте подтверждение email и сброс пароля;
- добавьте rate limiting и защиту от автоматического перебора паролей;
- проверьте все API endpoints и политику хранения персональных данных;
- не храните секреты в приложении Android;
- убедитесь, что все игровые услуги соответствуют правилам игрового сервера.

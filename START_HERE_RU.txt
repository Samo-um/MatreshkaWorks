MATRESHKARP_WORKS — проект для Android

ВАЖНО:
- Это исходный проект, не готовый APK.
- Android-проект включает локальные файлы web-интерфейса, поэтому экран приложения может открыться без размещённого сайта.
- Регистрация, заказы и чат требуют работающего backend-сервера. В web/app.js API_BASE сейчас указывает на localhost и должен быть заменён на реальный HTTPS API URL перед реальным использованием.

КАК ОТКРЫТЬ НА ТЕЛЕФОНЕ:
1. Полностью распакуй ZIP в папку без пробелов, например Download/MATRESHKARPFIXED.
2. В IDE используй Open Project и выбери именно папку android, где находятся settings.gradle и build.gradle.
3. Если IDE запускает ./gradlew, скрипт скачает Gradle 8.9 при наличии интернета и Java. Если среда не позволяет скачивать Gradle/SDK, используй сборку через GitHub Actions.

СБОРКА APK ЧЕРЕЗ GITHUB (если IDE на телефоне не собирает):
1. Создай репозиторий GitHub.
2. Загрузи содержимое архива, чтобы папки android, backend, web и .github лежали в корне репозитория.
3. Открой Actions → Build MATRESHKARP_WORKS APK → Run workflow.
4. После успешной сборки скачай artifact MATRESHKARP_WORKS-debug-apk и извлеки app-debug.apk.

Не публикуй пароли, токены и приватные данные в репозитории. APK debug предназначен для тестирования.
